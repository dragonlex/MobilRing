# Бюро находок

Приложение для бюро находок: публикуешь объявление о пропаже или находке, сервер сам ищет
совпадения и присылает их в «Уведомления». Есть фото вещи, фильтры ленты, переписка внутри
приложения, настройки приватности и перенос аккаунта по ключу.

Написано на Kotlin и Jetpack Compose, данные лежат в Firebase Realtime Database.

---

## Сборка

Нужны Android Studio (JDK 21) и файл `app/google-services.json` — он уже в репозитории.

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Установка на телефон:

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

Готовых релизов пока нет, приложение собирается из исходников.

## Экраны

- Главный — сообщить о пропаже или находке, уведомления, профиль.
- Все объявления — лента с фото, поиск по тексту, категории, место, период.
- Объявление — описание, фото, контакты автора, звонок, чат.
- Сообщения и чат — переписка по конкретному объявлению.
- Уведомления — найденные совпадения.
- Профиль — контакты, приватность, ключ восстановления.
- Справка — инструкция и правила безопасности.

## Как устроено

Код разделён на три слоя:

- `data/` — модели и работа с Firebase: `FirebaseRepo`, `DbFeed`, `ProfileStore`, `ChatRepo`.
- `ui/` — экраны, компоненты и тема.
- `*Activity.kt` в корне — связка между ними и переходы между экранами.

Совпадения ищет не приложение, а отдельный сервис
[MobilRing-Server2](https://github.com/dragonlex/MobilRing-Server2): он читает базу и пишет
пары в узел `matches`. Приложение только показывает готовые пары участникам.

Подсказка описания («ПОМОЧЬ С ОПИСАНИЕМ») тоже идёт через базу, без прямого запроса на
компьютер: приложение кладёт заявку в узел `assist` и подписывается на неё, сервис
дописывает туда готовый текст, приложение забирает его, показывает «ОК» и удаляет заявку.
Описание всегда не длиннее 110 слов.

Фото вещи хранится прямо в объявлении в base64: сжимается до 720 px по длинной стороне,
Firebase Storage не используется.

## Права

- `INTERNET` — база и вход в Firebase.
- `CALL_PHONE` — кнопка «ПОЗВОНИТЬ» набирает номер сразу. Без разрешения или без SIM
  открывается обычная клавиатура набора.
